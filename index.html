rfarris-dch

That name is not text. It is 160,000 points of light, drawn by your graphics card in a single call.

Move the pointer through it. Click it. Then scroll ↓

01 / Vertex shader morphing

The CPU is doing nothing.

Each particle carries where it was and where it is going. The blend, the stagger and the turbulence between them run in GLSL on the GPU, so JavaScript sends one number per frame: scroll position.

02 / Numerical integration

Chaos, solved at load.

This is the Lorenz system, σ=10 ρ=28 β=8/3, stepped 160,000 times across eight trajectories that began a hair apart. They never repeat and never leave the butterfly.

03 / Procedural geometry

Sixty racks, zero models.

No meshes, textures or files were downloaded for this data hall. Every cabinet edge, status light and floor tile is a point placed by arithmetic in under 40 milliseconds.

04 / Rejection sampling

A planet from noise.

Points are scattered over a sphere and kept only where a noise field rises above sea level, which leaves continents. The leftovers are thrown into orbit as rings.

05 / HDR post-processing

Then the light gets developed.

The frame renders in 16-bit float, blooms through a five-level mip chain, picks up lens fringing and film grain, and is tone-mapped with the ACES filmic curve. About 600 lines, one HTML file.
